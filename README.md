# Yoga Wellness & Aerobics — Jabalpur

Dark-mode, single-page marketing site for Yoga Wellness & Aerobics in Jabalpur, India — part of a batch of premium landing pages built for local studios.

## Stack

A single `index.html` — vanilla HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally

```bash
npx serve .
```

or just open `index.html` in a browser.
